# OWASP audit · 2026-10-28 · v0.4.0 (Google sign-in)

Scope: `api/**`, `src/lib/standup-client.ts`, `vercel.json`, dependencies.

| Risk | Check | Result |
|---|---|---|
| A01 Access control | `/api/standup` needs a signed session for an `ALLOWED_EMAILS` account; allow-list re-checked on every request, so removing an email revokes access at once | ✅ |
| A02 Crypto | HMAC-SHA256 cookies with signed `typ` + `exp`, constant-time compare, `AUTH_SECRET` ≥ 32 chars; `HttpOnly; SameSite=Lax; Secure` | ✅ |
| A03 Injection | Zod-validated body, notes sent as data in `<notes>`, grounded output, text rendering only | ✅ |
| A04 Design | Fail closed (503) when any variable is missing; per-account limiter 10/min, sign-in 20/min per IP; size caps | ✅ (limiter is per instance: a cost brake, not a boundary) |
| A05 Misconfiguration | CSP `default-src 'self'` unchanged (sign-in is a top-level navigation); generic client errors | ✅ |
| A06 Components | `npm audit --omit=dev`: 0 vulnerabilities; no new runtime dependency (esbuild is dev-only, exact version) | ✅ |
| A07 Auth | Code + PKCE (S256), `state` + `nonce`, ID token signature/`iss`/`aud`/`exp`/`email_verified`, app only sees ok/denied | ✅ |
| A08 Integrity | Lockfile committed, no new script host | ✅ |
| A09 Logging | Logs status codes, error names and token-check reasons only; never tokens, emails, notes or keys | ✅ |
| A10 SSRF | Fixed hosts only (`GOOGLE` constants, Claude API via SDK); redirect URI built from env `APP_URL`, never the Host header | ✅ |
| CSRF | Cookie-authenticated POST/DELETE require `Sec-Fetch-Site: same-origin` (or matching `Origin`) | ✅ |

Open items: none High. Live checks after deploy: `npm run smoke` is not set up yet (Week 5), and `npm run eval` needs a key.
